Part 6 - Keys and certificates

Skip this part if you are not using secure exchange.

6.1 Generate two certificates into backend\tls

Two, not one. The sender must trust partner.pem and reject clinic-local.pem, which is what case T11 demonstrates.

cd "C:\Users\lliam\StudioProjects\clinic_follow_up_reminder_system\backend"
$openssl = "C:\Program Files\Git\usr\bin\openssl.exe"
New-Item -ItemType Directory -Force -Path tls | Out-Null

& $openssl req -x509 -newkey rsa:2048 -sha256 -days 365 -nodes `
  -keyout tls\partner-key.pem -out tls\partner.pem `
  -subj "/CN=localhost" `
  -addext "subjectAltName=DNS:localhost,IP:127.0.0.1" 2>&1 | Select-Object -Last 1

& $openssl req -x509 -newkey rsa:2048 -sha256 -days 365 -nodes `
  -keyout tls\clinic-local-key.pem -out tls\clinic-local.pem `
  -subj "/CN=localhost" `
  -addext "subjectAltName=DNS:localhost,IP:127.0.0.1" 2>&1 | Select-Object -Last 1

Get-ChildItem tls | Select-Object Name, Length

-addext subjectAltName is mandatory. Without it the certificate loads fine and TLS fails on hostname validation much later, which is a harder error to trace than a missing file.

6.2 Generate the key pairs

node --env-file=.env scripts\secure-keys.js
Get-ChildItem keys | Select-Object Name, Length

Required: five files - sender-private.pem, sender-public.pem, recipient-private.pem, recipient-public.pem, ref.key.

If the script reports that material already exists, it was generated before. Do not pass --force unless you intend a rotation, which makes every previously sealed envelope unreadable.

Use *>&1, not 2>&1. The star merges every stream into plain strings. With 2>&1, PowerShell wraps any stderr line as an error record, and the evidence file then records a NativeCommandError for a build that succeeded.

When errors do appear they are almost always one of these:

MessageFix
new_with_undefined_constructor_default on ClinicApi()the client is a singleton: use ClinicApi.instance and never construct one
final_not_initialized_constructora final ClinicApi api; field survived a constructor edit - delete the field and the parameter
undefined_identifier: ctxthe dialog builder needs a block body with a named parameter
argument_type_not_assignable on appBarui.dart defines appBar(String title, {actions, bottom}) - one positional argument only

function Set-ModeVerified([string]$x) {
  @{ mode = $x } | ConvertTo-Json -Compress | Set-Content -NoNewline .mode.json
  $raw = curl.exe -s -X POST "http://127.0.0.1:4699/_/mode" -H "Content-Type: application/json" --data-binary "@.mode.json"
  $applied = ($raw | ConvertFrom-Json).mode
  if ($applied -ne $x) { throw "mode not applied: asked '$x', gateway reports '$applied'" }
  $st = curl.exe -s "http://127.0.0.1:4699/_/state" | ConvertFrom-Json
  "mode = $($st.mode)   calls so far = $($st.calls)"
}
